# 架构设计（ARCHITECTURE）

## 设计主轴：三层"懂 Noon"

| 层级 | 含义 | 实现方式 | 状态 |
|------|------|----------|------|
| L1 规则懂 | 平台硬规则：尺寸/白底/禁止元素/品类期望 | 结构化 YAML + 确定性检查器，可断言 | P0 已实现 |
| L2 审美懂 | 海湾市场审美：色板/场景/节庆/构图 | 专家先验 + 爆款店铺图片统计校准 | 先验已建，P2 数据校准 |
| L3 转化懂 | 什么图真的能卖 | 与销量/评价数据关联，启发式起步 | 规划中 |

通用 AI 生图工具只有提示词层；本项目把"懂 Noon"做成**可版本化、可校验、可迭代的资产**。

## 分层架构

```
输入：商品原图 + SKU 信息
        │
        ▼
┌─────────────────────────────────────────────┐
│  Noon 知识层（壁垒所在）                       │
│  ├── noon_image_rules.yaml   平台规则         │
│  ├── gulf_aesthetics.yaml    审美预设         │
│  └── cultural_redlines.yaml  文化红线         │
└─────────────────────────────────────────────┘
        │ 知识注入（提示词构建 + 校验规则）
        ▼
┌──────────────┬──────────────┬──────────────┐
│ 主图规范化     │ 场景图生成     │ 详情图排版    │
│ 白底·尺寸     │ 生活场景       │ 阿语 RTL     │
│ 去水印·居中    │ 审美预设       │ 双语卖点      │
└──────────────┴──────────────┴──────────────┘
        │
        ▼
┌─────────────────────────────────────────────┐
│ 质检闭环                                      │
│  规范校验（可断言） + 视觉基线评分（P2）          │
└─────────────────────────────────────────────┘
        │
        ▼
输出：上架素材包（主图 + 场景图 + 详情图）+ 整改清单
```

## 模块职责

| 模块 | 文件 | 职责 |
|------|------|------|
| 知识层 | `knowledge/*.yaml` + `src/noon_stylist/knowledge.py` | 规则/审美/红线的加载、查询、提示词构建 |
| 规范校验 | `src/noon_stylist/checker.py` | 主图 9 类检查：尺寸、比例、白底（商品以外区域）、四角纯色、主体占比、居中、贴边、边框、格式 |
| 主图流水线 | `pipeline.py::local_normalize_main / generate_main` | 本地：裁纯色底、去透明、补白、居中、方形化；模型：图生图重绘背景 |
| 场景图 | `pipeline.py::generate_scene` | 场景 + 色板 + 节庆 → 提示词 → 图生图 |
| 详情图排版 | `compose.py` | 真实字体渲染阿语（arabic-reshaper + bidi），绝不交给图像模型画字 |
| 模型层 | `models/` | ImageModel 抽象 + Gemini(Nano Banana)/OpenAI 兼容实现 + Mock；BYOK，Key 只走环境变量 |
| CLI | `cli.py` | check / presets / main / scene / detail |

## 关键设计决策

1. **白底只算商品以外区域**——否则"商品占比 60%"与"白底占比 92%"必然矛盾
2. **四角纯色检测**——抓住影棚米色/灰色底被误判为商品主体的情况
3. **纯色底裁切而非抠图**——影棚照四角一致时先裁边，无模型也能出合格主图；复杂背景留给图生图
4. **阿语必须真实字体渲染**——图像模型画阿语连写必出乱码
5. **BYOK 不锁定供应商**——`providers.yaml` 换行即切模型，新增供应商实现两个方法即可

## 路线图

- **P0（当前）**：知识层 + 主图校验 + 本地规范化 + 详情排版 + 可插拔模型层
- **P1**：真实商品图实测调优（含图生图主图/场景图效果）
- **P2**：竞品视觉基线——复用 noon-uae-selection 抓爆款店铺商品图 → 类目风格统计 → 生成图打分
- **P3**：Streamlit 工作台 + 批量 SKU 处理
- **P4**：与 Noon Profit Copilot 串成"选品 → 优化上架 → 利润验证"闭环
